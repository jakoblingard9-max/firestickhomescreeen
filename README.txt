FIRE TV HOME - build steps
1. Install Android Studio (free) and open this folder (FireTVHome).
2. Let it sync, then Build > Build APK(s).
3. Sideload app-debug.apk onto the Firestick (Downloader app or "adb install").
4. Open "My Home" from Your Apps & Channels. It scans your installed apps each time you open it.
Edit the page in app/src/main/assets/index.html (themes, birthdays, names).
